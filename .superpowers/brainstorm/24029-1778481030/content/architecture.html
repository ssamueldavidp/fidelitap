🔐 Capas de Seguridad (Defense in Depth)
🃏 Anti-fraude de Tarjetas
  • Cada tarjeta = UUID v4 + HMAC-SHA256 firmado con secret del negocio
  • El QR contiene un token firmado, no el UUID crudo
  • Tokens de escaneo con TTL de 60s (rotación automática)
  • Un sello por tarjeta por sesión de negocio (idempotencia)
  • Audit log inmutable de cada sello (IP, timestamp, device fingerprint)
🛡️ Aislamiento de Datos
  • Row Level Security (RLS) en todas las tablas — negocios solo ven sus datos
  • Multi-tenancy a nivel DB: business_id en cada registro
  • Supabase Storage con policies: solo el negocio accede sus archivos
  • Roles separados: business_owner, customer, admin
⚡ API & Rate Limiting
  • Rate limiting en endpoints de sello: 10 req/min por negocio
  • Rate limiting en login: 5 intentos, bloqueo 15min
  • Todos los inputs validados con Zod antes de tocar DB
  • Headers de seguridad: CSP, HSTS, X-Frame-Options via Next.js config
  • CORS estricto — solo dominios autorizados
🔑 Autenticación
  • JWT con expiración 15min + refresh token rotativo
  • Sesiones de negocio en httpOnly cookies (no localStorage)
  • 2FA opcional para negocios (Supabase TOTP)
  • OAuth Google como opción de login
  • Passwords hasheados con bcrypt (Supabase Auth)
