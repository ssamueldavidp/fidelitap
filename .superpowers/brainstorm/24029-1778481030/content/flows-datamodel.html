Diseño — Sección 2: Flujos de Usuario & Modelo de Datos

Dos actores principales: el Negocio y el Cliente final

🏪 Flujo del Negocio (dueño que adquiere FideliTap)
📝
1. Registro
Email + contraseña o Google OAuth. Elige plan (Freemium o Suscripción).
→
🎨
2. Crear Tarjeta
Editor visual: color, fondo, ícono de sello, nombre del beneficio, cantidad de sellos. Preview en tiempo real.
→
📄
3. Plantilla
Recibe PDF/imagen para imprimir o compartir digitalmente. Explica cómo el cliente activa su tarjeta.
→
📊
4. Dashboard
Ve sus clientes registrados, sellos acumulados, canjes realizados, métricas de retención.
→
📷
5. Dar Sello
Escanea QR del cliente o ingresa código único. El sello se refleja al instante en la Wallet del cliente.
🙋 Flujo del Cliente final
🔗
1. Activa tarjeta
Escanea QR del negocio o accede al link de la plantilla.
→
📋
2. Registro rápido
Nombre + email (o teléfono). Sin contraseña — link mágico o código SMS.
→
📱
3. Agregar a Wallet
Un tap para agregar a Apple Wallet o Google Wallet. La tarjeta tiene QR único + marca de agua FideliTap.
→
⬡⬡⬡
4. Acumula sellos
Por cada visita, el negocio escanea y el sello aparece en tiempo real en la Wallet.
→
🎁
5. Canjea beneficio
Al completar, la tarjeta muestra "COMPLETA". El negocio valida y la tarjeta se reinicia automáticamente.
🗄️ Modelo de Datos (PostgreSQL)
businesses
id uuid PK
name text
email text UNIQUE
plan enum(free,basic,pro)
subscription_status
wompi_customer_id
created_at timestamptz
RLS: solo el dueño accede
loyalty_cards
id uuid PK
business_id uuid FK
name text
stamps_required int
benefit_description text
design_config jsonb
{color, bg, icon, font}
is_active bool
RLS: negocio ve sus tarjetas
customers
id uuid PK
email text UNIQUE
name text
phone text
created_at timestamptz
RLS: cliente ve solo sus datos
customer_cards
id uuid PK
customer_id uuid FK
loyalty_card_id uuid FK
unique_code text UNIQUE
HMAC-SHA256 firmado
current_stamps int default 0
is_complete bool
wallet_pass_serial text
wallet_auth_token text
RLS: cliente + negocio
stamp_events
id uuid PK
customer_card_id uuid FK
business_id uuid FK
stamped_by uuid FK
ip_address inet
device_fingerprint text
scan_token text
created_at timestamptz
Inmutable — sin UPDATE/DELETE
subscription_plans
id uuid PK
name text
price_cop int
max_loyalty_cards int
max_customers int
features jsonb
Freemium: 1 tarjeta, 50 clientes
Basic: 3 tarjetas, 500 clientes
Pro: ilimitado
