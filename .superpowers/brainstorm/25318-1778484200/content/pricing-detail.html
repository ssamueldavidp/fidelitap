¿Cómo se reparte el costo de infraestructura?

La infra es un costo fijo de ~$337,050 COP/mes. Se distribuye entre todos los negocios activos usando un sistema de "unidades de peso".

Costos fijos mensuales totales

▲
Vercel Pro
Hosting del frontend Next.js + API Routes + CDN global. Incluye builds ilimitados y Edge Functions.
$84,000/mes
🗄
Supabase Pro
PostgreSQL 8GB + Auth + Storage 100GB + Realtime. El Realtime es clave para actualizar los sellos en Wallet al instante.
$105,000/mes
🍎
Apple Developer Program
Certificado obligatorio para firmar archivos .pkpass de Apple Wallet. Sin esto no se pueden generar pases de Apple.
$34,650/mes
📧
Resend (emails)
Emails transaccionales: bienvenida, confirmación de sello, tarjeta completada, facturas. 50,000 emails/mes.
$84,000/mes
⚡
Upstash Redis
Rate limiting anti-fraude: máx 10 sellos/min por negocio y bloqueo de fuerza bruta en login.
~$21,000/mes
🌐
Dominio fidelitap.co
Registro anual del dominio.
~$8,400/mes
Sistema de unidades de peso por plan
Freemium = 0.5 unidades (usa pocos recursos, no paga) Basic = 1.0 unidades (uso moderado, 3 tarjetas, 500 clientes) Pro = 2.0 unidades (mayor uso, 10 tarjetas, 2K clientes, métricas) Premium = 4.0 unidades (uso alto, ilimitado + API + multi-sede)
Ejemplo a 100 negocios (50 Basic + 30 Pro + 20 Premium)
Total unidades = 50×1 + 30×2 + 20×4 = 190 unidades Costo/unidad = $337,050 ÷ 190 = $1,774/unidad ───────────────────────────────────── Infra Basic = 1 × $1,774 = $1,774/mes Infra Pro = 2 × $1,774 = $3,548/mes Infra Premium = 4 × $1,774 = $7,096/mes

Cómo escala la infra con más clientes

20 negocios pagos → costo infra por negocio~$16,800/mes
50 negocios pagos → costo infra por negocio~$6,700/mes
100 negocios pagos → costo infra por negocio~$3,370/mes
200 negocios pagos → costo infra por negocio~$1,685/mes

ℹ️ El margen mejora significativamente con la escala. A 200+ negocios la infra por cliente es casi despreciable.

Margen por comisión de Wompi

Wompi cobra por cada transacción de suscripción. Así afecta tu margen real.

¿Cómo cobra Wompi?

El negocio paga su suscripción mensual → Se genera una transacción en Wompi
Wompi descuenta su comisión automáticamente → Antes de transferirte el dinero
Recibes el neto en tu cuenta bancaria → Entre 1–3 días hábiles

💡 Estrategia para reducir comisión Wompi

✓
Incentivar pago por PSE — solo 0.9%+$900 vs 2.69%+$900 en tarjeta. Ofrecer descuento de $5,000 COP/mes si pagan por PSE.
✓
Cobro anual anticipado — ofrece 1 mes gratis por pago anual. Reduces transacciones de 12 a 1 por año, la comisión de Wompi se aplica solo una vez.
✓
A >200 negocios, negociar con Wompi tarifa corporativa (suelen bajar a ~1.8% para volumen).
