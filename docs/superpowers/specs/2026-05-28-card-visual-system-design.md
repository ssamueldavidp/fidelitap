# Fidelitap — Card Visual System Design Spec

**Date:** 2026-05-28
**Status:** Approved by user
**Scope:** Card visual system redesign + editor improvements (no drag & drop)

---

## Goal

Elevar el sistema visual de tarjetas de Fidelitap a nivel de productos internacionales reales (Apple Wallet, Loyalz, Revolut, Starbucks Rewards). El negocio que contrata Fidelitap puede personalizar su tarjeta. El layout y el branding de Fidelitap son fijos.

---

## Reference

Usuario aportó imagen de referencia: tarjeta de Loyalz (competidor) con fondo crema, nombre del negocio grande en color de marca, grid de stamps con iconos filled/empty, stats de progreso, QR grande centrado, "Powered by Loyalz" abajo.

---

## Card Anatomy (layout fijo — top to bottom)

```
┌─────────────────────────────────────┐
│  NOMBRE DEL NEGOCIO    [LOGO/EMOJI] │  ← business name (uppercase, brand color) + logo
│─────────────────────────────────────│
│  [●][●][●][○][○][○][○][○]          │  ← stamps grid (4 cols)
│─────────────────────────────────────│
│  [🎁] Premio al completar    3 / 8  │  ← reward banner (NEW)
│       1 café americano gratis       │
│─────────────────────────────────────│
│  Hasta próx premio  │ Premios disp. │  ← stats row (2 cols)
│  5 sellos           │ 0 premios     │
│─────────────────────────────────────│
│           ┌─────────┐              │
│           │  QR     │              │  ← QR code (white container, centered)
│           └─────────┘              │
│        Powered by Fidelitap        │  ← fixed branding
└─────────────────────────────────────┘
```

### Zones — what business customizes vs what is fixed

| Zone | Type | Details |
|------|------|---------|
| Business name | **Customizable** | Large, bold, uppercase, brand color. Text entered by business owner. |
| Logo / emoji | **Customizable** | Business uploads logo image OR picks emoji. Displayed top-right in rounded container with brand color background. |
| Stamps grid | **Customizable** | Count (2–20), emoji/icon for each stamp. Filled = brand color + shadow. Empty = dashed border, greyscale, 0.35 opacity. |
| Reward banner | **Customizable** | Prize description text + reward icon emoji. Progress counter (X/total) shown right-aligned. Background tinted with brand color. |
| Stats labels | **Customizable** | Auto-calculated: "hasta próx premio" (stamps remaining) + "premios disponibles" (completed rounds not yet claimed). |
| Card background | **Customizable** | Light (cream `#F5F0E8`) or dark (business sets dark hex). Auto-selected based on color luminance, or manual toggle. |
| QR code | **Fixed** | Generated by Fidelitap per customer card. White container, rounded corners. Cannot be repositioned or removed. |
| "Powered by Fidelitap" | **Fixed** | Always present below QR. Small, subtle. Cannot be removed in any plan. |

## Card Style System — 5 Styles

Business owner picks ONE style when creating a card. All styles share the same layout anatomy above.

### Style 1 — Clean (Primary / Default)
**Inspiration:** Loyalz, Apple Wallet passes, minimal fintech cards
**Background:** Cream `#F5F0E8` (light) or custom dark hex
**Typography:** System sans-serif, extra-bold for business name
**Stamps:** Circular, brand color fill + shadow for active; dashed border empty
**Details:** No extra overlays. Pure layout, color does all the work.
**Slug:** `clean`

### Style 2 — Modern Premium
**Inspiration:** Apple Wallet dark, Revolut, Stripe
**Background:** `linear-gradient(145deg, #080e17, #0d1520, #060f18)`
**Details:** Radial glow in brand color (top-right corner), 1px shine line at top, subtle blue orb bottom-left
**Stamps:** Circular with gradient fill + glow shadow
**Progress bar:** 2px line under stamps showing % completion
**Slug:** `modern`

### Style 3 — Luxury Dark
**Inspiration:** Amex Black, VIP membership cards
**Background:** `#0a0a0a` with subtle cross-hatch texture (0.012 opacity)
**Details:** Gold radial orb top-right, gold accent divider line, progress bar in gold gradient
**Accent color:** `#c9a227` (gold) overlaid on brand color for details
**Stamps:** Circular, gold gradient fill for active
**Slug:** `luxury`

### Style 4 — Editorial / Event
**Inspiration:** Boarding passes, sports tickets, festival passes
**Background:** Deep gradient `linear-gradient(160deg, #1a0038, #0d0d22, #001a38)` + color orbs
**Details:** Bold oversized stamp count top-right. Square stamps (not circular) with rounded corners. Dashed separator line between body and footer (with circle cutouts on sides — classic boarding pass effect).
**Typography:** Larger business name, editorial hierarchy
**Slug:** `editorial`

### Style 5 — Minimal Clean
**Inspiration:** Notion, Linear, Scandinavian design
**Background:** `#f8f8f8` (near white)
**Details:** 3px accent bar at very top in brand color. Minimal shadows. No gradients. Typography does all the work.
**Stamps:** Solid circle, brand color fill; light grey empty
**Slug:** `minimal`

## Customization Options (per card)

```typescript
interface CardDesignConfig {
  style: 'clean' | 'modern' | 'luxury' | 'editorial' | 'minimal'
  color: string              // brand hex color (e.g. "#1d4ed8")
  bg_mode: 'light' | 'dark' // for 'clean' style only; others are always dark
  stamp_icon: string         // emoji string (e.g. "☕")
  logo_url?: string | null   // uploaded business logo (optional, replaces emoji in header)
  font: 'default' | 'rounded' | 'mono'
  // existing fields
  bg_type: 'solid' | 'image'
  bg_image_url?: string | null
}
```

**Color picker:** Curated palette of 12 colors + hex input. Colors: #1d4ed8, #0f766e, #7c3aed, #dc2626, #d97706, #16a34a, #db2777, #0ea5e9, #111827, #f97316, #be185d, #059669.

**Logo upload:** Optional. Max 2MB, JPG/PNG/WebP. Displayed in 54×54px rounded container top-right. If no logo, shows emoji instead.

## Stamp States

| State | Visual |
|-------|--------|
| Active / filled | Brand color background + box-shadow glow (0 4px 16px brand-color/35%) + emoji visible |
| Empty / unfilled | Transparent background + dashed border (brand color at 20% opacity) + emoji visible at 35% opacity + greyscale filter |
| Last filled (just stamped) | Same as active + scale-up animation + glow pulse (Framer Motion) |
| Complete (all filled) | All stamps pulse + confetti trigger |

## QR Code Section (always fixed)

```
┌──────────────────┐
│  white container │
│  border-radius:  │
│  14px            │
│  padding: 12px   │
│  shadow: subtle  │
│  QR: 100×100px   │
└──────────────────┘
   Powered by Fidelitap   ← 12px, color #aaa (light) / #444 (dark)
```

The QR is generated via `qrcode` npm library (already installed). Container is always white regardless of card style so the QR scans correctly.

## Card Editor Improvements

The current editor (`src/components/cards/card-editor.tsx`) is a basic form + preview. Improvements:

### Layout
- **Left sidebar** (320px fixed): form controls organized in collapsible sections
- **Right area** (flex-1): large live preview, centered, with phone mockup frame optional

### Sections in sidebar
1. **Información**: name input, prize description input, stamp count slider
2. **Estilo**: horizontal style selector (5 clickable card thumbnails)
3. **Marca**: color picker (grid of swatches + hex input), logo upload, emoji picker
4. **Fondo**: toggle light/dark (for Clean style), optional background photo upload

### Live preview
- Full card rendered in real time as user edits
- Shows realistic card at ~300px width
- Smooth transitions on color/style change (Framer Motion `animate` on color values)

### Animations (Framer Motion)
- Style thumbnail selection: scale + border transition
- Color swatch hover: scale(1.15)
- Card preview: `layoutId` for smooth rerender on style switch
- Stamp icons: stagger-in on initial load

---

## Responsive Behavior

Cards render at:
- **Dashboard preview (CardWidget):** ~220px width, all 5 styles
- **Drawer preview (CardDrawer):** ~260px width
- **Editor live preview:** ~300px width
- **Customer-facing (/c/[slug]):** full mobile width, max 360px
- **Apple Wallet pass:** handled separately by wallet generation lib (unchanged)

No text truncation allowed. Business name wraps to 2 lines max (clamp). Stamp grid: 4 columns always, wraps naturally.

- All 5 card styles render correctly at all preview sizes
- Business owner can pick style + color + logo/emoji in editor
- Live preview updates in real time (<16ms per frame)
- QR always visible and scannable
- "Powered by Fidelitap" always present

- TypeScript: 0 errors
- No regression in existing wallet generation
